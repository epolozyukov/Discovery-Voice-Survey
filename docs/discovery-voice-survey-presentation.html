Why this solution

Run discovery interviews at scale: participants just talk, and you get their exact words.

Free of charge

Built entirely on free tiers: Supabase for data and auth, Vercel for hosting, Groq for speech-to-text. No licences, no per-response fees at pilot scale.

€0 to run a pilot

No typing, just voice

Participants tap once and speak. It is faster and more natural than a form, so answers are richer and completion is higher, on any phone or laptop.

Tap, talk, done

No hallucination

No generative AI writes or summarises anything. The answer is a transcription of what was said, and the participant can review and edit it before submitting.

Architecture

Three managed services, no servers to run

SupabaseManaged Postgres, auth and row-level security out of the box; generous free tier; open source, so no lock-in.
Groq + WhisperVery fast transcription (near real time) on a free tier. Whisper is multilingual, and the OpenAI-compatible API lets us swap providers via one env variable.
Vercel + Next.jsZero-ops hosting with preview deployments. The API key never reaches the browser, and there is no LLM in the loop to invent content.
